#  City Bus Management System

A menu-driven application developed in C to manage city bus operations, routes, passengers, fare calculations, and basic operational analytics.

##  Project Overview

This project demonstrates how C programming can be used to manage bus-related information. It uses file handling to store and retrieve records between program executions.

##  Features

- Bus management
- Route management
- Passenger management
- Fare calculation
- Basic operational analytics
- File handling for data storage
- Menu-driven interface

## Technologies Used

- C Programming Language
- Structures and Functions
- File Handling
- Binary Files

##  Project Objective

To demonstrate practical C programming concepts by developing a simple, menu-driven city bus management application.
